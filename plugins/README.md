# Your tools go here

1. Ask any AI for a tool, pasting in `WIDGET-GUIDE.md` from the main folder.
2. Save what it gives you here as `<id>.recipe.md`.
3. Add the file name to the list in `plugins.json`, for example
   `"recipes": ["networking-prep.recipe.md"]`.

This folder is yours. Updates to the hub never change it.
