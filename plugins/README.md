# Your tools go here

1. Paste `WIDGET-GUIDE.md` from the main folder into any AI and ask it for a
   tool.
2. Save what it gives you in this folder as `<id>.recipe.md`.

That's it. The hub finds new files here on its own; tap Refresh on the home
screen if a new tool doesn't show up.

`plugins.json` is a backup list, used only if the hub can't reach GitHub. You
can ignore it.

This folder is yours. Updates to the hub never change it.
